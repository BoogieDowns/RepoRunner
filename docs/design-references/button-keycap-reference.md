# RepoRunner Button Keycap Design Reference

## Purpose

This document is a visual styling reference for RepoRunner's main action buttons.

The goal is to restyle RepoRunner's action buttons so they feel like old physical computer keyboard keys or control-board keycaps.

This is a styling reference only. Do not copy the colors from the images.

## What to copy from the references

Copy the physical qualities:

- raised rectangular keycap shape
- softly rounded corners
- smaller raised top surface inside the button
- beveled or sloped outer edges
- matte material, not shiny glass
- soft top-left lighting
- darker bottom and right edge shadow
- tactile press-down active state
- old computer keyboard / physical control-board feel

## What not to copy

Do not copy:

- orange color
- white color
- exact image dimensions
- image text
- modern flat button styling
- glossy glass/acrylic shine

## RepoRunner constraints

Keep the current RepoRunner visual language:

- dark background
- crimson / dark red primary buttons
- smoky neutral secondary buttons
- deeper red danger button
- same font
- same text size
- same icons
- same labels
- same spacing
- same button order
- same behavior

## Buttons in scope

Apply this styling to the shared `.btn-glass` action-button system:

- Start Frontend
- Start Backend
- Stop Engine
- Pull
- Install
- Restart
- Open
- Setup Save Configuration button

Leave small toolbar buttons such as Copy and Clear unchanged unless explicitly asked later.
