Please do one **small refinement pass** on the **Frontend / Backend service status indicators only**.

Do **not** redesign the UI.
Do **not** change layout.
Do **not** change functionality.
Do **not** change buttons, logs, modal, meteors, branding, service logic, IPC, or product flow.

This is only about improving the **service status lights**.

## Goal

Keep the current idea:

* illuminated status indicator
* status text inside it (`RUNNING`, `STOPPED`, `STARTING`, `STOPPING`)
* red lit treatment for active states
* darker unlit treatment for stopped states

But refine it in two ways:

1. make it look **more like a realistic plastic indicator light**
2. make the shape **more square / boxy**, not rounded-pill

---

## 1. Make the indicator more square

Right now the indicator still feels a bit too rounded.

Please change the light shape so it feels more like:

* a small **square-edged rectangular module**
* old hardware / control-panel light
* slightly sharp corners
* not a pill
* not soft capsule-shaped

Use:

* a more rectangular silhouette
* smaller border radius
* squarer edges
* a slightly more industrial shape

Still keep it neat and premium — not chunky or ugly.

---

## 2. Make it look more like real translucent plastic

The status light should feel like:

* a physical old-school red plastic lens
* translucent illuminated plastic
* subtle depth
* slightly smoked acrylic / polycarbonate look
* realistic face material

Add more believable material cues such as:

* subtle inner glow
* slight lens thickness
* faint inset shadow
* edge bevel
* darker outer housing / bezel

It should not read as a flat digital badge.

---

## 3. Add realistic lens ribbing / texture

The face of the indicator should have visible but subtle:

* fine horizontal grooves
* ribbed plastic lens texture
* faint lens lines like a real warning light

This should feel like real molded plastic detail, not decorative stripes.

Keep it:

* subtle
* realistic
* low contrast
* visible enough to help sell the material

---

## 4. Improve the highlight / reflection

Please add a more convincing specular highlight so it feels like a real object.

For example:

* soft glossy highlight near the top edge
* faint reflection across the lens face
* subtle surface sheen

Do **not** make it glassy, chrome, or overly shiny.
It should feel like **plastic with internal illumination**.

---

## 5. Running should feel physically lit

For `RUNNING`:

* keep the red illumination
* keep the gentle pulse
* keep the glow

But make it feel more like:

* a real illuminated warning module
* internal light behind translucent plastic
* warm industrial light

Not:

* neon
* sci-fi laser
* flat red UI badge

---

## 6. Stopped should feel like the same object turned off

For `STOPPED`:

* keep the exact same structure / shape
* same square-edged module
* same plastic lens texture

But make it:

* much darker
* low-glow or no-glow
* smoked dark red / near-black lens
* still readable

So it feels like the same physical indicator in the off state.

---

## 7. Keep the text inside and readable

Keep the status text inside the light:

* `RUNNING`
* `STOPPED`
* `STARTING`
* `STOPPING`

Make sure the text is:

* centered
* crisp
* readable
* visually integrated with the light

Do not let texture or glow overpower the label.

---

## Important restraint

Do not make it:

* larger
* flashy
* overly bright
* cartoonish
* overly glossy
* too rounded
* too futuristic

The target is:

* realistic
* tactile
* square-edged
* industrial
* premium
* subtle

---

## Preserve everything else

Do not change:

* service card layout
* wording
* button styling
* logs
* modal
* page structure
* meteor effect
* branding
* functionality

---

## Acceptance criteria

After this change:

1. The service indicators are more square / boxy in shape.
2. They no longer feel like rounded pills.
3. The lights feel more like real plastic indicator modules.
4. The lens has subtle ribbing / horizontal texture.
5. `RUNNING` feels physically illuminated.
6. `STOPPED` feels like the same module turned off.
7. The text remains inside and readable.
8. No unrelated UI or functionality changes are made.
