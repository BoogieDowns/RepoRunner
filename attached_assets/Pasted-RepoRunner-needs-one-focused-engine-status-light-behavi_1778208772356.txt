I want the light to stay **red throughout the whole process**.

The wording can change, but the light color should remain red.

```text
STARTING
RUNNING
STOPPING
STOPPED
```

But the light color behavior should be:

```text
STARTING = red light fading on
RUNNING = solid red illuminated light
STOPPING = red light fading off
STOPPED = unlit/dark light
```

## Remove loading circle

Remove the small loading circle / spinner that appears during:

```text
STARTING
STOPPING
```

I do not want a spinner/loading circle inside the light.

## Keep the same size

The status light module should remain the same size in every state.

Do not let the light change width or height when the text changes.

The light should not jump, resize, shift, or reflow.

## Illumination behavior

### STARTING

When the status changes to `STARTING`, the red light should gradually fade on.

Desired behavior:

```text
unlit/dark → red light fades on → reaches full red when running
```

Suggested timing:

```text
1.5s–2.0s
```

Use best judgment. Around `1.8s` is fine.

### RUNNING

When the status is `RUNNING`, the red light should stay steadily illuminated.

No pulsing.

No spinner.

No animation after it is fully lit.

### STOPPING

When the status changes to `STOPPING`, the red light should gradually fade out.

Desired behavior:

```text
red illuminated → slowly fades down while stopping → unlit/dark when stopped
```

The fade-out should take roughly the same amount of time as the stopping process/state transition.

Suggested timing:

```text
1.5s–2.0s
```

Around `1.8s` is fine unless the existing stop transition is shorter.

### STOPPED

When status is `STOPPED`, the light should be dark/unlit.

It should still look like the same physical plastic light module, just turned off.

## Important behavior distinction

Do not use repeated pulse animations.

Do not use peach/orange transition states.

Do not use a spinner.

Use only:

* red illuminated state
* red fade-on during starting
