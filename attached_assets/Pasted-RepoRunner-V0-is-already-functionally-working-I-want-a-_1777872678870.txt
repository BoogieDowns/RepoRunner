## Design direction

### 1. Overall mood

Shift RepoRunner away from the current green theme and toward a **dark black/red signal theme**.

The app should feel:

* near-black
* low-key
* slightly ominous / cinematic
* premium
* technical
* restrained
* intentional

Not flashy.
Not neon cyberpunk overload.
Not gamer RGB.

* “dark mission control”

## 2. Core visual language

Use the reference image as inspiration for the visual system.

### Background

Use a near-black background with very subtle:

* film grain / noise
* faint texture
* possibly subtle vertical streaking or scanline feel

Keep it subtle. It should enrich the atmosphere without hurting readability.

### Accent color

Use a restrained red accent color, something in the range of:

```css
#cc2222
#d12b2b
#e03a3a
```

Use red sparingly:

* active highlights
* running-state visuals
* important active indicators
* subtle beam effects
* selected / focus accents

Do not make the whole app red.

### Surfaces

Cards/panels should stay dark and elegant:

* charcoal / black surfaces
* subtle borders
* low-contrast separation
* slight glass/metal/control-panel feel if tasteful

### Typography

Typography should feel more deliberate and atmospheric.

Recommended direction:

* headings / labels / system text: JetBrains Mono, IBM Plex Mono, or another good monospace / technical font
* supporting UI text can remain a clean sans if needed, but the system should feel mostly unified and technical

I like the reference’s narrow/industrial/system feel, but please keep RepoRunner readable and practical.

Avoid novelty fonts that hurt usability.

## 4. Main visual feature: falling red lines + moon/horizon motif

This is the key thematic feature I want.

### Background motif

Introduce a subtle background composition inspired by the reference image:

* thin vertical red lines descending from the upper area of the screen
* a dark half-moon / horizon / planetary arc visual near the bottom or lower-mid area
* the descending red lines visually “impact” or converge toward the horizon area

This should be treated as a subtle branded atmospheric layer, not a giant illustration that overwhelms the UI.

### Behavior

I specifically want this effect to communicate that a repo is running.

#### When no services are running

* keep the atmospheric background very quiet
* the moon/horizon can remain faint
* maybe only extremely subtle or nearly absent vertical lines

#### When a repo/service is running

* show subtle animated vertical red lines descending
* have them feel like signal beams or telemetry lines hitting the horizon/moon
* this should visually imply activity / execution / live repo state

#### When both frontend and backend are running

* the effect can become slightly more alive:

  * a few more vertical lines
  * slightly brighter red impact zone
  * subtle pulsing at the horizon impact point

Important:

* keep animation subtle
* do not make it distracting
* do not hurt performance
* do not obscure buttons or logs
* do not make the UI feel gimmicky

This should feel like ambient product atmosphere.
