## Important visual rule

I want **one consistent branded red system**.

That means:

* same underlying red hue
* only state-based variation allowed
* variation should come from opacity / brightness / glow / hover state
* not from switching to visibly different reds

Right now some reds feel mismatched.
After this pass, all red accents should feel like they come from the same brand source.

---

## State guidance

It is fine for different states to vary slightly, but only within the same red family.

For example:

* idle = base RR logo red
* hover = slightly brighter version of same red
* active = slightly deeper version of same red
* glow = transparent version of same red
* disabled = dimmed / low-opacity version of same red

Do **not** drift into:

* orange-red
* pink-red
* magenta-red
* blood-red
* generic UI red

Keep it anchored to the logo red.

---
