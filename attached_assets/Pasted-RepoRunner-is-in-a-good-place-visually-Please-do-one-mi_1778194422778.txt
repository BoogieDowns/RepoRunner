## 2. Add depth to the meteor effect

The current red falling meteors look good, but I want them to feel more layered and atmospheric.

Please add **foreground / midground / background depth** to the meteor system.

### Desired direction

The meteor field should feel more cinematic and dimensional, with:

* some **smaller, fainter** meteors in the background
* some **normal** meteors in the mid layer
* a few **slightly larger, brighter** meteors in the foreground

This should create a subtle sense of depth.

### Important behavior

Keep the existing meteor behavior system intact:

* they should still spawn from above the viewport
* they should still fall downward naturally
* they should still fade through the interface
* they should still stop spawning when services are not running
* existing meteors should still finish their fall after stop

Do **not** break the current lifecycle logic.
