RepoRunner is working well. After the small UX fixes, please do one final **mini polish pass**.

This should be restrained and tasteful. Do **not** redesign the app. Do **not** change product behavior. Do **not** add features.

## Goal

Make the current UI feel a little more finished, balanced, and premium while preserving the exact layout and functionality.

## Polish areas

### 1. Header refinement

Make the top header feel slightly more intentional.

Please refine:

* logo spacing
* RepoRunner wordmark alignment
* project name spacing
* repo path readability
* Edit Setup alignment

The header should feel calm, clean, and product-like.

Do not re-add the duplicate service status pills in the header.

### 2. Typography pass

Improve text hierarchy subtly.

Focus on:

* section labels like `QUICK ACTIONS`, `SERVICES`, `APP LOGS`
* project name
* repo path
* form labels
* helper text
* button labels
* logs text

Use consistent weights and sizes.
Avoid text that feels too tiny, too bold, or too low-contrast.

### 3. Button spacing and states

Make buttons feel more polished and consistent.

Please check:

* equal button heights
* consistent icon spacing
* consistent padding
* hover states
* disabled states
* active/pressed states if easy
* danger button styling

Do not change button labels.
Do not add new buttons.

### 4. Card polish

Make the dashboard cards feel slightly more refined.

Please adjust:

* border contrast
* corner radius
* internal padding
* section dividers
* subtle shadows or depth if appropriate
* spacing between Quick Actions and Services

Keep the app dark and simple.

### 5. Setup panel polish

Make the setup card feel consistent with the dashboard.

Please refine:

* close X positioning and hover state
* title/subtitle spacing
* form grid alignment
* helper text spacing
* input styling
* Save Configuration button alignment

Do not add new fields.
Do not remove existing fields.

### 6. Logs polish

Make the logs area easier to read.

Please refine:

* log row spacing
* source label color balance
* timestamp contrast
* empty state styling
* Copy/Clear alignment
* header spacing

Keep logs monospace.
Do not add filters, tabs, search, or log levels.

### 7. Consistency pass

Look for small inconsistencies and clean them up:

* inconsistent margins
* slightly misaligned icons
* inconsistent capitalization
* mismatched border colors
* inconsistent hover effects
* awkward empty space

## Strict constraints

Do not change:

* Electron IPC
* process management
* port checking
* restart logic
* command execution
* config persistence
* setup fields
* app navigation behavior
* service statuses

Do not add:

* IDE features
* terminal tabs
* GitHub login
* cloning
* branch switching
* deployment
* AI debugging
* multi-project support
* analytics
* charts
* extra settings

## Acceptance criteria

After this mini polish pass:

1. The app looks a bit more finished and cohesive.
2. The current layout is preserved.
3. The header feels cleaner.
4. Typography feels more consistent.
5. Buttons feel more polished.
6. Cards feel more refined.
7. Setup panel feels consistent with the dashboard.
8. Logs are easier to scan.
9. No new features were added.
10. No existing functionality was broken.
