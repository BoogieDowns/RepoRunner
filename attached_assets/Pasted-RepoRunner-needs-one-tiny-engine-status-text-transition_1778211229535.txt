```text
STARTING
```

to:

```text
RUNNING
```

The light/lens illumination can continue its smooth animation, but the text should update immediately.

```text
STARTING → RUNNING
```

the text should switch immediately to:

```text
RUNNING
```

at whatever brightness/luminance the light currently has.

So visually:

```text
light continues its smooth illumination
text changes instantly from STARTING to RUNNING
```

The text should not restart a fade animation.

The text should not fade from transparent.

The text should not animate opacity.

The lens/background/glow can animate.

The text should not.

Please separate the text layer from the animated light layer if needed.

Suggested structure:

```text
status indicator container
  animated lens/glow layer
  static text layer
```

Only the lens/glow layer should animate.

The text layer should update instantly and remain stable.
