RepoRunner is looking good. Please do a focused refinement pass on the **Quick Actions buttons only**.

Do **not** redesign the app.
Do **not** change layout.
Do **not** change functionality.
Do **not** change logs, engine/status lights, meteors, setup modal, service logic, IPC, or product flow.

This is only about making the main action buttons look **more convincingly glossy/glass-like**.

## Reference direction

Use this reference as visual inspiration:

```text
https://media.istockphoto.com/id/697831138/vector/computer-icons-from-the-bright-colored-glass.jpg?s=612x612&w=0&k=20&c=qAxmGX6UK3Y65pUuid2NwGpr-KJKFfbnF-SLxkRiWBc=
```

I like the sense of:

* glossy glass surface
* strong top highlight
* layered shine
* internal depth
* reflective bevel
* polished icon/button material

But adapt it to RepoRunner’s current black/red sci-fi UI.

Do **not** copy the bright colorful look directly.
RepoRunner should stay dark, premium, and controlled.

## Target buttons

Apply this to the Quick Actions buttons:

* Pull Latest
* Install
* Start Frontend
* Start Backend
* Stop Engine
* Restart All
* Open Preview

## Desired result

The buttons should feel more like:

* dark glossy glass
* polished smoked glass
* reflective physical controls
* premium app-icon-like material
* high-end glass UI
* tactile and clickable

They currently look a bit glassy, but still too flat/matte. Push the glass effect further.

## Specific styling improvements

### 1. Stronger top glass highlight

Add a more visible curved or banded highlight across the upper part of each button.

It should look like light reflecting off a glossy glass surface.

This can be done with:

* a brighter top gradient
* a pseudo-element highlight
* a soft white/gray translucent shine
* a curved or angled reflective band if possible

Keep it tasteful, but make it clearly visible.

### 2. Add internal depth

Make the button face feel like it has material thickness.

Use:

* inner shadows
* inset highlights
* darker lower gradient
* edge shading
* subtle internal glow for red buttons

The button should feel like a physical glass piece, not a flat rectangle.

### 3. Stronger beveled edge

Give the button edges more realistic glass beveling.

Use:

* brighter upper/left edge
* darker lower/right edge
* subtle rim light
* inner border highlight

This should make the button look cut from glass or polished acrylic.

### 4. Reflective lower depth

The bottom part of the button can be slightly darker and richer, like the reference.

Use a layered vertical gradient:

* brighter at top
* richer/darker in the middle/lower section
* subtle bottom edge shadow

### 5. Preserve dark RepoRunner theme

The buttons should **not** become bright colorful app icons.

Keep:

* neutral buttons as smoky charcoal glass
* start buttons as dark red-tinted glass
* Stop Engine as stronger red glass
* disabled buttons muted and less reflective

The material can be glossier, but the palette should stay dark and controlled.

## Interaction states

### Hover

Hover should make the glass catch light slightly more:

* slightly brighter highlight
* slightly stronger edge reflection
* subtle lift/depth

### Active/pressed

Pressed state should feel like the glass button depresses:

* slightly darker
* reduced top highlight
* subtle inset shadow

### Disabled

Disabled buttons should still have the same shape/material language, but:

* much dimmer
* lower contrast
* less shine
* clearly inactive

## Important constraints

Do not:

* change button labels
* change button order
* change click behavior
* change disabled logic
* make buttons bigger
* make buttons cartoonish
* make them look wet
* make them look like bright mobile app icons
* add animated shine sweeps
* change the surrounding cards/layout

## Acceptance criteria

After this change:

1. The Quick Actions buttons have a noticeably stronger glossy glass effect.
2. The top highlight is clearly visible.
3. The buttons feel more reflective and tactile.
4. Edges feel more beveled/polished.
5. The style still fits the dark black/red RepoRunner UI.
6. Neutral, start, stop, and disabled states remain visually distinct.
7. No layout or functionality changes are made.
