Do **not** change buttons, services card, logs panel, status pills, colors, or branding.

## Goal

When I click **Edit Setup**, the setup panel should feel like a polished floating modal over the existing dashboard.

## Requested behavior

### 1. Keep the dashboard visible behind the modal

When the setup modal opens:

* the current dashboard should remain visible in the background
* do not replace the page with a blank setup screen
* do not navigate away visually
* the modal should appear above the current dashboard

### 2. Add a subtle dark overlay/scrim

Behind the setup modal, add a subtle dark overlay.

Desired feel:

* background dashboard is still visible
* background is darkened slightly
* focus moves to the setup panel
* not too heavy or opaque

Suggested styling:

```css
background: rgba(0, 0, 0, 0.45);
backdrop-filter: blur(2px);
```

Use best judgment to fit the current black/red style.

### 3. Make the setup panel feel floating

The modal card should feel slightly elevated above the page.

Suggested treatment:

* subtle border
* soft shadow
* very restrained red glow or edge highlight
* no big bright effects

Keep it tasteful and consistent with the current UI.

### 4. Add subtle open animation

When the modal opens:

* fade in gently
* scale from about `0.97` to `1`
* use a quick smooth ease
* duration around `140ms–220ms`

It should feel polished, not dramatic.

### 5. Add subtle close animation

When closing with the X:

* do not instantly disappear
* add a very small “bubble pop” feel
* subtle only

Suggested behavior:

* scale very slightly down or up for a moment
* fade out
* duration around `120ms–180ms`
* use easing that feels soft

Important:

* do not make it cartoonish
* do not make it slow
* do not make it bounce dramatically

### 6. Preserve modal behavior

Keep existing behavior:

* Save Configuration still saves
* X closes without saving
* fields stay the same
* validation stays the same
* no auto-save on close

After this change:

1. Clicking Edit Setup opens the setup modal over the current dashboard.
