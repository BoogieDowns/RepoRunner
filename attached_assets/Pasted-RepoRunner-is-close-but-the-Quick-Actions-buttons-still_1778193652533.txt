RepoRunner is close, but the Quick Actions buttons still read slightly too matte / polished-plastic rather than true glossy glass.

Please do one more refinement pass on the **Quick Actions buttons only**.

Do **not** redesign the app.
Do **not** change layout.
Do **not** change functionality.
Do **not** change logs, engine indicators, meteors, modal, typography, spacing, or product flow.

This is only about making the buttons feel **more convincingly glassy, reflective, and three-dimensional**.

## Goal

Push the buttons further toward a true **glass / glossy acrylic** look.

Right now they have some gloss, but they still feel too flat and matte.

They should feel more like:

* smoked glass
* glossy acrylic
* iPhone-style reflective UI material
* physical polished controls
* premium high-contrast glass buttons

## Buttons in scope

Apply this only to the Quick Actions buttons:

* Pull Latest
* Install
* Start Frontend
* Start Backend
* Stop Engine
* Restart All
* Open Preview

## What to improve

### 1. Stronger specular top highlight

The most important fix:

Add a more obvious glossy reflective highlight across the **upper portion** of each button.

This should feel like real light reflecting off curved glass.

Use something like:

* a bright translucent white/gray highlight
* concentrated near the top third
* slightly curved or banded
* stronger than the current version
* tapering softly as it moves downward

It should be clearly visible, but still premium.

### 2. Add a distinct glass face + body separation

The button should feel like it has layers:

* glossy front face
* inner body beneath
* darker lower depth

Please introduce more separation between:

* the reflective top face
* the richer/darker lower half
* the outer beveled shell

Right now this layering is too subtle.

### 3. Darker lower half for depth

Make the lower half of each button slightly darker and richer so the top highlight pops more.

The face should not be evenly lit.

Use a clearer value shift:

* brighter / more reflective at top
* mid-tone center
* darker lower section

This will make the glass look thicker and more dimensional.

### 4. Crisper bevel and edge reflections

Increase the realism of the edge treatment:

* brighter upper rim light
* subtle inner bevel highlight
* darker lower edge shadow
* slightly clearer outer contour

The edges should feel cut, polished, and reflective.

### 5. Add a secondary internal reflection

If possible, add a faint secondary reflective streak or inner sheen inside the button face.

For example:

* a soft narrow reflective band
* or a faint internal glow line
* or subtle light catching the inner bevel

This should help the buttons feel more like actual glass and less like flat gradients.

### 6. Keep the style restrained

Important:
Do **not** make the buttons cartoonish, candy-like, or overly shiny.

Avoid:

* rainbow highlights
* overly rounded “gel” look
* toy-like shine
* excessive white glare
* animated sweeps

This still needs to fit RepoRunner’s dark black/red sci-fi aesthetic.

## Color behavior

Keep the current color families:

* neutral buttons = smoky charcoal / gray glass
* Start buttons = dark red glass
* Stop Engine = stronger red glass
* disabled buttons = dimmed, muted glass version

Do not change the palette direction.
Only improve the material rendering.

## Interaction states

Keep hover/active logic the same, but let the improved glass material carry through:

### Hover

* slightly brighter reflective highlight
* slight lift in gloss
* subtle depth increase

### Pressed

* slightly reduced highlight
* slightly darker face
* gentle inset feel

### Disabled

* same structure
* much dimmer
* reduced shine
* still visibly glass, but inactive

## Acceptance criteria

After this change:

1. The buttons feel noticeably more glassy and reflective.
2. The top highlight is stronger and more obvious.
3. The lower half feels darker/richer, creating more depth.
4. The buttons feel layered rather than flat.
5. The bevel/edge reflections are crisper.
6. The effect still feels premium and restrained.
7. The buttons fit the current RepoRunner aesthetic.
8. No layout or functionality changes are made.
