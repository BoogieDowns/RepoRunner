## Goal

Keep the current smoked-glass button styling, but make the buttons feel a little more convincingly reflective.

Important:

* only a subtle increase
* not too shiny
* not glossy plastic
* not bright glassmorphism
* not wet-looking
* not flashy

I want the buttons to feel like:

* dark smoked glass
* slightly more reflective
* premium
* realistic
* restrained

## Requested refinement

Please slightly increase the reflective/specular quality of the dashboard action buttons:

* Pull Latest
* Install
* Start Frontend
* Start Backend
* Stop Services
* Restart All
* Open Preview

## What to change

### 1. Slightly stronger top highlight

Increase the subtle top reflective sheen a little.

Possible implementation:

* slightly brighter top-edge highlight
* slightly clearer upper gradient band
* a bit more definition in the top reflective strip

But keep it restrained and realistic.

### 2. Add or refine a faint reflection layer

If helpful, add or tune a very subtle reflection pass, such as:

* faint angled sheen
* soft light streak
* gentle reflective bloom across the upper third of the button

This should be extremely subtle.

It should help the button read more like glass, not attract attention by itself.

### 3. Slightly improve hover reflection

On hover:

* the reflective quality can become a little more noticeable
* the button can feel a touch more “alive”
* but still remain dark and premium

Do not over-brighten the hover state.

### 4. Preserve the smoked-glass body

Do not lose the current darker base.

The buttons should still feel like:

* dark smoked glass
* subtle red-tinted or neutral glass depending on button type
* consistent with the black/red sci-fi RepoRunner aesthetic

## Important constraints
