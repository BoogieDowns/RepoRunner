Replit added a peach pulse for `STARTING` and `STOPPING`, but it is too subtle.

It currently uses:

```text
rr-indicator-peach-pulse
```

```text
3.6s
```

That is too slow and too faint. I can hardly see it.

## Requested change

Make the `STARTING` and `STOPPING` peach pulse:

1. the **same timing length** as the red `RUNNING` pulse
2. slightly **brighter / more visible**

## Timing

Change the peach pulse duration to match the red running pulse.

If the red running pulse is:

```text
2.8s
```

then the peach transition pulse should also be:

```text
2.8s
```

Do not make it faster than the red running pulse.

Just match the timing.

* outer peach glow intensity
* border glow brightness
* lens internal glow

* peach highlight strength

A good target is:

```text
20–35% more visible than it is now
```

* distracting
