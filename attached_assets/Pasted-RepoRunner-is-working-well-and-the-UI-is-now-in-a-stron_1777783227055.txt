The current top-left logo feels too placeholder/basic.

Please replace it with a **cleaner, more intentional brand mark** for RepoRunner.

### Logo direction

Design a very simple logo mark that fits the product and current dark green theme.

Good directions could include a subtle combination of ideas like:

* repo / branch / flow
* run / forward motion
* a stylized “R”
* a minimal geometric mark suggesting motion, launch, or execution
* a clean app icon-like symbol

### Constraints for the logo

* Keep it minimal
* Keep it geometric and clean
* It should work at small size in the header
* It should feel like a SaaS/product logo, not a gaming logo
* It should fit the green theme
* Avoid anything too literal, cartoonish, or overcomplicated
* Avoid terminal prompt clichés like `>_`

A refined simple mark is better than something clever-but-messy.

### Styling direction

* Use the current green palette
* Slight soft glow is okay, but subtle
* The logo should feel crisp and intentional
* It should sit comfortably in the current header

## 3. Upgrade the app font system

The current font is one of the last things letting the UI down.

Please choose a **better font system** for the app.

### Desired feel

The font should feel:

* modern
* clean
* crisp
* readable
* slightly technical/product-oriented
* good in dark UI
* good at small sizes

### Recommendation

Use a polished modern UI font such as one of these if available:

* **Inter**
* **Geist**
* **IBM Plex Sans**
* **Plus Jakarta Sans**

Use your best judgment, but I would prefer something in this family of clean modern product fonts.

### Suggested typography system

A good approach would be:

* **UI font** for interface text, buttons, headers, form labels, service labels, helper text
* **Monospace font** only for logs and possibly small technical metadata

For monospace, something like:

* **JetBrains Mono**
* **IBM Plex Mono**
* **SF Mono** fallback
* **ui-monospace**

Do **not** use monospace for the whole app.
Only use it where it makes sense, especially logs.
