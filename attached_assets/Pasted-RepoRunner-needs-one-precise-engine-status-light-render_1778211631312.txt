RepoRunner needs one **precise engine/status light rendering fix** only.

Do **not** redesign the UI.
Do **not** change layout.
Do **not** change functionality.
Do **not** change service logic, process management, IPC, setup behavior, logs, buttons, meteors, or product flow.

This is only about the **relationship between the engine light illumination and the text inside it**.

## Current problem

We are almost there, but the status text and the light illumination still feel like separate animated things.

What I want is simpler:

The **whole illuminated light module**, including the text, should have one continuous luminance level.

Only the actual letters should change.

For example:

```text
STARTING → RUNNING
```

The light should not restart.
The text should not fade separately.
The text should not flash.
The text should not animate independently.

The word should simply swap from `STARTING` to `RUNNING` while the whole light continues at whatever illumination level it already has.

## Desired behavior

### During STARTING

The entire red plastic light module should gradually illuminate.

That includes:

* lens
* glow
* red plastic surface
* text visibility/brightness

The text should look like it belongs to the illuminated light.

### When STARTING changes to RUNNING

Only the letters change:

```text
STARTING
```

becomes:

```text
RUNNING
```

The overall light illumination should continue smoothly.

There should be:

* no fade-in of the new text
* no opacity reset
* no text flash
* no light restart
* no visual jump
* no separate text animation

The luminance should be continuous.

### During RUNNING

The whole module stays steadily illuminated red.

### During STOPPING

The whole red plastic light module dims down continuously.

That includes:

* lens
* glow
* red plastic surface
* text visibility/brightness

### When STOPPING changes to STOPPED

Only the letters change to:

```text
STOPPED
```

The light should continue to the dark/unlit state.

No white text flash.

The final red flicker, if present, should still feel like the light/lens flickers, not the text separately flashing white.

## Implementation direction

Please avoid animating the text as a separate opacity/fade layer.

Instead, make the status text inherit the same visual/luminance state as the light module.

A good structure would be:

```text
status light container
  illuminated lens/background/glow
  text label rendered normally
```

But the text should not have its own transition/animation that resets on status changes.

If there are CSS transitions on the text element, remove them.

If React re-mounts the text element on status changes, avoid that if possible.

Do not key/remount the text span by status if that causes fade or animation.

Keep the same text element and simply change its string.

## Important principle

The animation belongs to the **light state**, not the **word**.

The word should change instantly.

The light should continue smoothly.

## Preserve current good behavior

Keep:

* independent Frontend / Backend light animations
* smooth fade-on during starting
* steady red running state
* smooth fade-down during stopping
* final red shutdown flicker if already working
* no spinner
* no pulsing
* same size
* same red plastic/ribbed lens style

## Do not change

Do not change:

* service status logic
* actual start/stop timing
* button behavior
* logs
* meteors
* setup modal
* layout
* app functionality

## Acceptance criteria

After this fix:

1. During `STARTING`, the whole light module illuminates smoothly.
2. When text changes from `STARTING` to `RUNNING`, only the letters change.
3. The illumination does not restart, jump, fade, or flash on `STARTING → RUNNING`.
4. The text does not fade separately.
5. The text does not flash white.
6. During `STOPPING`, the whole light module dims smoothly.
7. When text changes from `STOPPING` to `STOPPED`, only the letters change.
