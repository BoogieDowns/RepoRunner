## What needs to be fixed

Please refine the icon system so that all button icons share:

### 1. Matching scale
Each icon should occupy a similar optical footprint.

No icon should feel:
- too tiny
- too tall
- too wide
- too thin
- too heavy

Standardize them so they all feel equally sized next to their labels.

### 2. Matching stroke weight
Use a consistent stroke thickness across the whole set.

If one icon feels hairline-thin and another feels chunky, fix that.

They should all feel like they came from the same drawing system.

### 3. Matching baseline / vertical alignment
Every icon should sit cleanly in line with the LunaObscura button text.

No icon should feel too high or too low relative to:
- the button center
- the text baseline
- the button label block

### 4. Matching icon-to-text spacing
The gap between icon and label should be even and clean across all buttons.

No button should have:
- cramped icon/text spacing
- too much empty gap
- inconsistent spacing relative to others

### 5. Matching geometry / finish
All icons should feel like part of one premium sci-fi system.

They should share:
- similar roundness vs sharpness
- similar corner behavior
- similar line endings
- similar visual precision

### 6. Matching enabled / disabled rendering
Icons should behave consistently across states.

That means:
- enabled buttons: crisp, readable, polished
- disabled buttons: dimmed consistently, but still clean
- active red buttons: icon tint and contrast should match the label treatment
